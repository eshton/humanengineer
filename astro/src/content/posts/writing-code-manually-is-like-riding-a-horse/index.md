Writing code manually is like riding a horse. 🐎 It used to be a necessity, but these days, you mostly do it only for fun or therapy.

Yet manual code writing will not disappear, just as horses and mules didn't disappear with the invention of tractors. 🚜

We invented the tractor about 100 years ago, and it took over 95% of the jobs of pack animals. But technological replacements target use cases, not old technologies themselves.

Horses didn't disappear. Pack animals are still useful in many areas:

- 🏔️ Carrying heavy loads into roadless mountains
- 🚨 Disaster relief after roads disappear
- 🌲 Logging where tractors would damage the forest
- 🪖 Military logistics in extremely rough terrain (the US military still teaches pack-animal logistics)

AI can write code faster and better for things that were already heavily coded before. 🤖💻

Novel algorithms, entirely new language concepts, and anything involving real innovation will still need people to write code by hand.
