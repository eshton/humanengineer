You can assess an engineer's agentic adoption by asking a very simple
question: **Do you still write code manually?** 👨‍💻

If the answer is a straight no: good adoption. ✅ Anything else: no adoption.

A person needs to let go of writing code manually and learn how to make
everything safe, reliable, and much faster agentically. 🤖 The switch is
almost like a toggle, but one that takes a bit of a leap of faith.

So far, I've encountered the following concerns when talking about making
that leap:

- 😨 Am I going to lose my job? Are all of us?
- 🎛️ How do I stay in control?
- 👀 How can I review all the code the agent writes?
- 🔐 Is this safe?
- 💥 This company just went bankrupt because of AI.

Talking through all these concerns openly is a good start, and leading by
example helps people make the leap. 🚀
