Since I switched to agentic engineering, I have gradually extended my setup, one plugin and one MCP at a time. Right now, I am quite confident in my stack, as it supports 95% of my workflow.

Here are the configured, battle-tested tools I currently use:

- 🌐 **Chrome DevTools MCP** - live browser debugging and performance tracing
- 🪨 **Caveman** - compact AI responses (~65% fewer output tokens)
- ⚡ **RTK** - 60–90% token savings on terminal output
- 🚀 **Vercel MCP** - deployments and runtime logs
- ☁️ **Modal MCP** - deployments and runtime logs
- 📋 **Linear MCP** - issues, projects, and documentation
- 🗄️ **Supabase MCP** - read-only production data and logs
- ⚙️ **Claude Hooks** - enforce my workflow across agents
- 🧠 **Compound Engineering** - structured planning and review workflow
- 📊 **draw.io Skill** - architecture diagrams from natural language
