Everything is legacy now. 🚀

When I first heard this from Simon Bostock, I was mad at myself for not coming up with it earlier.

In the age of agents, the mathematics of what is possible and how long things take is being challenged. 1+1 is not 2 anymore. 🤯

Software written by hand is now legacy. With the help of agents, better work can be done: more efficient code can be written, superior solutions can be designed, tests can be written, edge cases can be found, bugs can be fixed, and improvements can be made. All in an instant. ⚡

Software written by hand belongs to an old world. And it needs an upgrade. 🔧

The upgrade is just one prompt away. ✨

Crazy times. 🤖
